# دليل التثبيت والمتطلبات (العربية)
## متطلبات التشغيل
- نظام التشغيل: Windows 10/11 x64 أو Linux x86-64 (النواة >= 5.15)
- الذاكرة العشوائية RAM: 8 جيجابايت كحد أدنى، و 16 جيجابايت مستحسن لتفريغات الذاكرة
- وحدة التخزين: مساحة 2 جيجابايت للتطبيق؛ وقرص تخزين خارجي مخصص لمخرجات الأدلة
- المترجم: GCC >= 12 أو Clang >= 15 أو MSVC >= 2022 لدعم معيار C++20
