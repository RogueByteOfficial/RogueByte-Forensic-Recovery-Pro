# دليل استخدام روغ بايت فورينسيك ريكفري برو (RFRP)
**المطور:** SidoDev-Dz  
**العلامة التجارية:** RogueByte  
**الإصدار:** 2.4.0-ForensicPro (محرك C++20 الأصلي وواجهة Qt 6)

## 1. المقدمة
يعد "روغ بايت فورينسيك ريكفري برو" محطة عمل احترافية موثقة للتحقيق الجنائي الرقمي واستعادة الأدلة. يلتزم البرنامج بقواعد الحفاظ على سلامة الأدلة في وضع القراءة فقط، وحساب بصمة SHA-256، والتوثيق الدقيق لسلسلة الحيازة.

## 2. سير العمل الجنائي
1. **[01] إدارة القضايا:** تهيئة حاوية التحقيق ومعرف القضية وسجلات التدقيق.
2. **[02] تسجيل الأدلة:** استيعاب صور الأقراص وتفريغات الذاكرة مع حساب البصمة فورياً.
3. **[03] سحب الذاكرة الحية RAM:** فحص قدرات المشغلات (WinPmem, LiME) وتأكيد المشغل قبل السحب.
4. **[07] عارض البايتات الست عشري:** فحص بايتات الذاكرة بعناوين 64-بت والتنقل الفوري.
5. **[09 و 10] استخراج الملفات بالتوقيع:** مسح محاذٍ للقطاعات لاستعادة JPEG, PNG, PDF, ZIP, ELF, PE.
6. **[11] التحقق من البصمات:** مقارنة البصمة الحالية مع بصمة أمر الضبط والتفتيش.
7. **[13] توليد التقرير الجنائي:** تصدير التقرير الموثق بتنسيق HTML و JSON و PDF باللغتين العربية والإنجليزية.
