# Installation Guide (English)
## System Requirements
- OS: Windows 10/11 x64 or Linux x86-64 (Kernel >= 5.15)
- RAM: 8 GB minimum, 16 GB+ recommended for memory dumps
- Storage: 2 GB for software; dedicated external drive for evidence output
- Compiler: GCC >= 12, Clang >= 15, or MSVC >= 2022 (C++20 support required)
